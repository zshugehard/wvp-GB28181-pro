## 1. 单一交付任务

### T-1：完成国标身份维护的端到端交付

- **作为** 平台管理员，
- **我希望** 在系统设置页维护国标编号、国标域和认证密码，并在保存后按字段语义即时生效或提示重启，
- **以便于** 不登录服务器修改 YAML 也能安全核对和更新接入身份，同时不中断既有视频业务。
- **验收边界**：AC-1、AC-2、AC-3、AC-4、AC-5、AC-6、AC-7 全部满足；这些 AC 是同一任务的验收项，不是可独立交付的 Story。
- **任务范围**：
  - 前端 `web/src/views/setting/SipServerConfig.vue`：密码显隐回显；国标域默认填充；前后端校验文案对齐；保存结果与重启标签区分。
  - 后端 `SettingServiceImpl`：国标编号、国标域、密码的必填与格式校验；YAML 写入；写盘成功后更新运行时 `SipConfig` 身份三元组；保存响应区分即时生效字段与需重启字段；失败路径不得谎报已生效。
  - 测试：后端参数化校验、保存与运行时更新测试；前端组件/行为测试；保留并更新现有 `SettingServiceImplTest`，不删除用例。
- **不在范围**：SIP Stack 热重建、端口/IP 热切换、密码加密存储、修改密码后强制注销设备、通过清空密码禁用公共密码。
- **规模**：单一 PR，预计 270~480 行（含测试）；若实际超出 500 行，先复核范围或另行取得用户确认，不以重新拆分 Story 规避约束。

### 验收边界

| 验收项 | 必须满足的边界 |
|---|---|
| AC-1 页面可编辑与回显 | 国标编号、国标域、认证密码三个字段可编辑；查询接口返回当前 YAML 中的明文密码；密码输入框提供显隐切换。 |
| AC-2 格式校验 | `id` 去除首尾空白后匹配 `^\d{20}$`；`domain` 去除首尾空白后匹配 `^\d{10}$`，不要求等于 `id` 前 10 位；`password` 空串或全空白拒绝保存；失败返回字段级错误且不写盘。 |
| AC-3 明文保存与回显 | YAML 与查询接口均使用明文密码，不使用 `******` 哨兵；保存后重新查询与提交值逐字符一致；空密码不进入保存成功路径。 |
| AC-4 后续请求生效 | 保存成功后，新的 `id/domain/password` 对后续注册鉴权、SIP From/To、SSRC/分组编码可见；已建立的注册与 Dialog 不被主动注销，也不要求立即重新校验。 |
| AC-5 原子性与失败回滚 | 校验失败不写盘、不改运行时值；写盘失败不改运行时值；写盘成功但运行时更新失败时接口返回失败且不谎报已生效；并发保存不得产生身份三元组交叉。 |
| AC-6 绑定字段重启语义 | `port/ip/showIp/timeout/alarm` 仍在 `restartRequiredFields`；保存响应区分即时生效字段与需重启字段；不自动重启服务。 |
| AC-7 国标域默认填充与弱一致 | 页面加载时 domain 为空且 id 有效则默认显示 id 前 10 位；编辑 id 时仅在 domain 为空或仍等于旧 id 前 10 位时自动填充；手工修改后不被覆盖；保存只校验 10 位数字格式。 |

### 实施顺序（执行提示，不是独立 Story）

1. 先写失败测试，覆盖 AC-2、AC-3、AC-4、AC-5、AC-6 的后端行为与 AC-1、AC-7 的前端行为。
2. 收敛后端校验规则与字段级错误，确保非法输入不写盘、不改内存。
3. 调整前端密码显隐、国标域默认填充、校验文案与保存结果提示。
4. 在写盘成功后整体更新运行时 `SipConfig` 身份三元组，并补齐失败路径。
5. 运行聚焦测试，再运行四大硬门禁，回写 `05-evidence.md`。

## 2. 测试策略

- **红**：先写失败测试，至少覆盖：
  - 保存后 `SipConfig.id/domain/password` 立即变为新值；
  - 非法 id/domain、空密码不写盘、不改内存；
  - domain 默认填充只跟随 id 前缀，手工值不被覆盖；
  - 写盘失败不改内存；
  - 查询返回明文密码；
  - 绑定字段仍出现在 `restartRequiredFields`；
  - 保存身份字段不主动注销已注册设备。
- **绿**：最小实现通过上述测试。
- **重构**：抽取身份快照/校验纯函数，删除重复规则，不保留旧的无条件重启提示。
- **回归**：保留并更新现有 `SettingServiceImplTest`；不删除任何用例。
